# Алгоритмы и C++

Решения контестов двух курсов первого года программы «Дизайн и разработка информационных
продуктов» (НИУ ВШЭ × Центральный университет): «Алгоритмы и структуры данных» и
«Язык программирования C++». 118 решений на C++.

## Структура

### [`алгосы/`](алгосы) — алгоритмы и структуры данных

11 контестов. Соревновательный формат: чтение из stdin, жёсткие ограничения по времени и памяти.
Общий каркас решения — в [`шаблон2.cpp`](алгосы/шаблон2.cpp).

### [`С++/`](С++) — язык C++

Задачи не на алгоритм, а на проектирование типов: собственные классы с корректной семантикой
значения, перегрузкой операторов и обработкой ошибок через исключения.

| Задача | О чём |
|---|---|
| [`Rational`](С++/контест_6/1) | Класс рационального числа: автоматическое сокращение дроби, полный набор арифметических операторов и операторов сравнения, ввод/вывод через потоки, собственное исключение `RationalDivisionByZero` |
| [`Matrix`](С++/контест_6/2) | Шаблон матрицы с размерностью в параметрах шаблона, арифметика матриц, транспонирование, исключения `MatrixOutOfRange` и `MatrixIsDegenerateError` |
| [`Range`](С++/контест_6/3) | Ленивый диапазон в духе `range()` из Python — итератор без материализации последовательности |
| [`Array`](С++/контест_6/4) | Шаблон статического массива с проверкой границ в `At()` и исключением `ArrayOutOfRange` |

## Как собрать

Отдельных зависимостей нет — только стандартная библиотека:

```bash
g++ -std=c++17 -O2 -o solution алгосы/контест_1/1.cpp
./solution < input.txt
```

Задачи из `С++/` собираются вместе со своими тестами:

```bash
g++ -std=c++17 -o test С++/контест_6/2/matrix_test.cpp && ./test
```
